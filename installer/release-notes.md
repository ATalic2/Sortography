## Download and install

Choose the file for your computer below. You do not need to install .NET.

| Computer | Download | Install |
| --- | --- | --- |
| Windows x64 | `Sortography-<version>-Setup.exe` | Run Setup, then open Sortography from Start. |
| Mac with Apple silicon | `Sortography-<version>-osx-arm64.dmg` | Open the disk image and drag Sortography into Applications. |
| Mac with Intel processor | `Sortography-<version>-osx-x64.dmg` | Open the disk image and drag Sortography into Applications. |
| Ubuntu 24.04 x64 | `Sortography-<version>-linux-x64.deb` | Open with your software installer, then launch from the applications menu. |

Windows also has a portable `.zip`: extract the whole archive and open `Sortography.exe`.
Linux has a portable `.tar.gz`: extract it and run `./Sortography` from that folder. System libraries are still required; the package targets Ubuntu 24.04.

These builds do not yet have publisher certificates. Windows may show an unrecognized-publisher warning; macOS may block opening the app because it is not notarized. On macOS, after trying to open it, follow [Apple's instructions for Open Anyway](https://support.apple.com/en-ie/102445) only if you trust this download. Managed computers may prohibit this.

To update, close Sortography and install the newer version in the same location. Windows users can uninstall it from Settings > Apps. Mac users can remove it from Applications. Linux package users can remove it with their software manager.

`SHA256SUMS.txt` contains checksums for the downloads. GitHub's automatically generated source archives are for building the project yourself.
